# Справочник функций лабораторной работы 3

Документ относится к текущим исходникам. Здесь перечислены все написанные C-функции программы и тестовой подмены, затем функции Python-проверок и замеров. Стандартные библиотечные функции перечислены отдельно в конце.

## Как проходит выполнение

`main → parse_options → ignore_sigpipe → read_problem → read_input → process_problem → apply_filter → run_pass → start_workers / run_rows / join_workers → convolve_rows → print_matrix`.

Стрелки показывают общий путь, а не точный линейный порядок каждого вызова. Ввод выполняется до расчёта; строки каждого прохода считаются параллельно.

## Структуры и соглашения

- `Matrix`: число строк, столбцов и указатель на непрерывный буфер double. Индекс элемента: `row * cols + col`.
- `RowTask`: указатели на общие матрицы, личный диапазон строк, код результата и pthread_t работника.
- `Reader`: буфер текущей строки, его ёмкость и признак терминального ввода.
- Большинство наших int-функций возвращают 0 при успехе, -1 при ошибке. Предикаты возвращают 0/ненулевое значение. У parse_options есть особый код 1 для справки.
- `static` ограничивает видимость вспомогательной функции текущим C-файлом.

## `skip_space`

Файл: `src/console.c`, строка 18.

```c
static void skip_space(char **cursor);
```

Принимает адрес указателя cursor и передвигает его через пробельные символы. Изменяет позицию разбора у вызывающей функции, поэтому используется char **. Значения char перед isspace приводятся к unsigned char. Ничего не возвращает.

## `parse_size`

Файл: `src/console.c`, строка 24.

```c
static int parse_size(char **cursor, size_t *value);
```

Разбирает одно положительное целое из строки через strtoumax. Проверяет начало токена, диапазон size_t и разделитель после числа. При успехе записывает число через value и двигает cursor, возвращает 0. При ошибке возвращает -1. Ноль, минус, дробная запись, переполнение и посторонние суффиксы не принимаются.

## `at_end`

Файл: `src/console.c`, строка 41.

```c
static int at_end(char *cursor);
```

Проверяет, остались ли после текущей позиции только пробельные символы и конец строки. Принимает указатель по значению, поэтому внешний cursor не меняет. Возвращает ненулевое значение для корректного конца.

## `read_line`

Файл: `src/console.c`, строка 46.

```c
static int read_line(Reader *reader, const char *prompt);
```

Читает всю строку через getline в буфер Reader, при необходимости увеличивая его. В интерактивном режиме печатает prompt и сбрасывает stderr перед ожиданием ввода. Возвращает 0 либо -1 при EOF/ошибке чтения и печатает причину. Память строки освобождает read_problem.

## `read_dimensions`

Файл: `src/console.c`, строка 62.

```c
static int read_dimensions(Reader *reader, size_t *rows, size_t *cols);
```

Читает одну строку с двумя положительными целыми: rows и cols. Использует parse_size дважды и at_end для запрета лишних данных. В терминале повторяет ошибочный ввод, при вводе из файла возвращает -1 сразу. Успех — 0, размеры записываются через указатели. Матрицу не выделяет.

## `read_size`

Файл: `src/console.c`, строка 76.

```c
static int read_size(Reader *reader, const char *prompt, size_t *value, int odd);
```

Читает одно положительное целое по подсказке prompt и записывает через value. Параметр odd дополнительно требует нечётность: для стороны ядра он включён, для K выключен. В терминале повторяет неверную строку, в файле прекращает ввод. Возвращает 0/-1.

## `parse_row`

Файл: `src/console.c`, строка 92.

```c
static int parse_row(char *cursor, double *values, size_t count);
```

Разбирает ровно count вещественных чисел в values через strtod. Отклоняет неверные токены, лишние числа, NaN/Inf и полный underflow ненулевого ввода в ноль; представимые ненулевые субнормальные значения допускает. Возвращает 0/-1. При ошибке часть строки уже могла быть записана: read_matrix требует повторить всю строку, которая перезапишет её целиком.

## `read_matrix`

Файл: `src/console.c`, строка 109.

```c
static int read_matrix(Reader *reader, Matrix *matrix, const char *name);
```

По очереди читает строки заранее выделенной матрицы. Показывает имя, номер строки и необходимое число значений. При ошибке повторяет только текущую строку в терминале; при файловом вводе возвращает -1. Возвращает 0 при заполнении всей матрицы. Не выделяет и не освобождает Matrix.data.

## `parse_options`

Файл: `src/console.c`, строка 138.

```c
int parse_options(int argc, char **argv, size_t *threads);
```

Обрабатывает argc/argv: без аргументов устанавливает лимит 1, с --threads P проверяет положительное P, с --help печатает справку. Возвращает 0 для обычного запуска, 1 для успешно показанной справки, -1 для ошибки. Матрицу не читает и потоки не создаёт.

## `read_input`

Файл: `src/console.c`, строка 168.

```c
static int read_input(Reader *reader, Matrix *matrix, Matrix *kernel, size_t *iterations);
```

Выполняет последовательность ввода задачи: размеры, выделение и строки исходной матрицы, сторона и выделение ядра, его строки, K. Использует Reader, принадлежащий read_problem. Возвращает 0/-1 с ранними выходами. Уже выделенные матрицы остаются доступны main для освобождения; функция не дублирует очистку на каждой ветке.

## `read_problem`

Файл: `src/console.c`, строка 193.

```c
int read_problem(Matrix *matrix, Matrix *kernel, size_t *iterations);
```

Владеет Reader и его динамическим буфером строки. Определяет интерактивность по stdin, выводит вводную подсказку, вызывает read_input, затем всегда освобождает reader.line. Возвращает код read_input. Матрицей и ядром владеет main.

## `print_matrix`

Файл: `src/console.c`, строка 205.

```c
int print_matrix(const Matrix *matrix);
```

Печатает матрицу построчно в stdout с точностью %.17g. В интерактивном режиме отдельно пишет заголовок в stderr. Проверяет printf, putchar и fflush. Возвращает 0 либо -1; память и содержимое матрицы не меняет.

## `run_rows`

Файл: `src/filter.c`, строка 19.

```c
static void *run_rows(void *argument);
```

Стартовая функция pthread с требуемым интерфейсом void * → void *. Приводит аргумент к RowTask, вызывает convolve_rows и сохраняет его код в task->result. Возвращает NULL; численный результат лежит в destination, а код ошибки — в задании. Та же функция вызывается главным потоком для собственного диапазона.

## `join_workers`

Файл: `src/filter.c`, строка 26.

```c
static int join_workers(RowTask *tasks, size_t started);
```

Принимает массив заданий и число успешно запущенных работников. Ожидает каждого через pthread_join и собирает статусы вычислений. Возвращает 0 либо -1 при вычислительной ошибке работника. Если сам join неуспешен, печатает ошибку и завершает процесс через _Exit: безопасный момент освобождения памяти неизвестен.

## `start_workers`

Файл: `src/filter.c`, строка 41.

```c
static int start_workers(RowTask *tasks, size_t count, RowTask *main_task, size_t *started);
```

Разбивает строки на count диапазонов и создаёт count-1 работников. tasks содержит отдельный RowTask каждому работнику; main_task остаётся с диапазоном главного. started увеличивается только после успешного pthread_create. Возвращает 0 либо возвращённый pthread код ошибки. При неудаче не ожидает работников сама: это обязанность run_pass. При count=1 цикл не выполняется, tasks может быть NULL.

## `run_pass`

Файл: `src/filter.c`, строка 58.

```c
static int run_pass(const Matrix *source, const Matrix *kernel, Matrix *destination, size_t limit);
```

Организует один многопоточный проход. Ограничивает число участников числом строк, выделяет задания, создаёт работников, считает диапазон главного, ожидает работников и освобождает задания. Даже при ошибке создания ожидает уже запущенных. Возвращает 0 или -1, переносит ошибку pthread в errno либо использует ERANGE для неконечного вычисления. Входную и выходную матрицы не освобождает.

## `is_filter_input_valid`

Файл: `src/filter.c`, строка 87.

```c
static int is_filter_input_valid(const Matrix *matrix,
                                 const Matrix *kernel,
                                 size_t iterations,
                                 size_t threads);
```

Именованный static-предикат проверки аргументов фильтра. Проверяет наличие обоих буферов, положительные K и число потоков, положительную нечётную сторону квадратного ядра. Возвращает ненулевое значение при успехе, 0 при нарушении. Ничего не выделяет и не печатает; позволяет читать apply_filter без длинного булева условия. Размер входной матрицы дополнительно проверит matrix_create при создании scratch.

## `apply_filter`

Файл: `src/filter.c`, строка 100.

```c
int apply_filter(Matrix *matrix, const Matrix *kernel, size_t iterations, size_t threads);
```

Принимает входную матрицу, ядро, K и число участников. Проверяет аргументы через is_filter_input_valid, выделяет scratch и K раз вызывает run_pass. После каждого успешного прохода меняет указатели буферов; копировать всю матрицу не нужно. Освобождает оставшийся вспомогательный буфер и возвращает 0/-1. В matrix остаётся итоговая матрица, которой владеет main. При ошибке после успешных проходов отката к первоначальному вводу нет.

## `ignore_sigpipe`

Файл: `src/main.c`, строка 9.

```c
static int ignore_sigpipe(void);
```

Настраивает игнорирование SIGPIPE через sigaction. Нужна, чтобы разрыв выходного канала можно было обработать как ошибку вывода. Возвращает 0 либо -1 с диагностикой; матрицами не владеет.

## `process_problem`

Файл: `src/main.c`, строка 18.

```c
static int process_problem(Matrix *matrix, const Matrix *kernel, size_t iterations, size_t limit);
```

Принимает заполненные матрицу и ядро, K и лимит потоков. Выбирает min(limit, rows), печатает PID и число участников, измеряет apply_filter через CLOCK_MONOTONIC и выводит результат. Чтение и печать не входят в измеренный интервал. При ошибке часов, расчёта или печати возвращает -1; освобождение матриц остаётся вызывающему main.

## `main`

Файл: `src/main.c`, строка 44.

```c
int main(int argc, char **argv);
```

Точка входа: разбирает параметры, обрабатывает справку и ошибки, настраивает SIGPIPE, читает задачу и запускает обработку. Владеет матрицей и ядром и освобождает оба буфера. Возвращает EXIT_SUCCESS либо EXIT_FAILURE.

## `matrix_create`

Файл: `src/matrix.c`, строка 7.

```c
int matrix_create(Matrix *matrix, size_t rows, size_t cols);
```

Принимает адрес Matrix и положительные rows/cols. Проверяет размеры и переполнение произведения до malloc, затем записывает размеры и указатель в Matrix. Возвращает 0 или -1, при недопустимых размерах задаёт EINVAL/EOVERFLOW. Выделенные значения ещё не инициализированы. Использовать нужно для пустого объекта: функция не освобождает ранее выделенный буфер.

## `convolve_rows`

Файл: `src/matrix.c`, строка 24.

```c
int convolve_rows(const Matrix *source,
                  const Matrix *kernel,
                  Matrix *destination,
                  size_t first_row,
                  size_t end_row);
```

Считает один проход для строк [first_row, end_row). source и kernel читаются, destination заполняется только в назначенных строках. Для каждой ячейки суммирует произведения по ядру; индексы center-u и center-v задают переворот. Выход за край пропускается, что соответствует нулям. Возвращает 0 или -1 при NaN/Inf, самостоятельно errno не устанавливает. Ожидает заранее выделенные совместимые матрицы и корректный диапазон; сама потоки не создаёт.

## `__wrap_pthread_create`

Файл: `tests/thread_failures.c`, строка 8.

```c
int __wrap_pthread_create(pthread_t *thread,
                          const pthread_attr_t *attributes,
                          void *(*start)(void *),
                          void *argument);
```

Только тестовая подмена. По LAB3_FAIL_CREATE возвращает EAGAIN на заданном вызове, иначе передаёт вызов настоящему pthread_create. Позволяет проверить очистку при частичном запуске работников. В обычный исполняемый файл не входит.

## `__wrap_pthread_join`

Файл: `tests/thread_failures.c`, строка 20.

```c
int __wrap_pthread_join(pthread_t thread, void **result);
```

Только тестовая подмена. По LAB3_FAIL_JOIN возвращает EINVAL на заданном вызове, иначе вызывает настоящий pthread_join. Проверяет аварийную ветку, где состояние работника неизвестно. В обычной программе не используется.

## Функции Python-скриптов

Тесты запускаются через `sh tests/run.sh`. Замеры и наблюдение потоков запускаются отдельно; они не являются частью обычного старта программы.

### `tests/benchmark.py`

| Функция | Назначение |
|---|---|
| `make_input` | Генерирует одинаковые воспроизводимые данные для бенчмарка заданного размера. |
| `measure` | Запускает фильтр, извлекает внутреннее elapsed_seconds и вычисляет SHA256 полного вывода. |
| `collect_measurements` | Проводит прогрев и пять перемешанных повторов P для трёх размеров, проверяет совпадение хешей и собирает сырые записи. |
| `summarize` | Для каждой пары размер/P вычисляет медиану, минимум, максимум, ускорение и эффективность. |
| `save_measurements` | Сохраняет CSV, JSON-таблицу и сведения об ОС, CPU, компиляторе и методике. |
| `main` | Собирает измерения, строит сводку, сохраняет результаты и печатает таблицу. |

### `tests/check.py`

| Функция | Назначение |
|---|---|
| `problem` | Собирает строку входных данных из матрицы, ядра и K. |
| `reference` | Считает эталонную последовательную свёртку на Python для сравнения с C. |
| `run_program` | Запускает выбранный исполняемый файл с входом, лимитом потоков и тайм-аутом; возвращает stdout, stderr и код завершения. |
| `assert_filter` | Сравнивает результат программы с эталоном, проверяет форму матрицы, числовую точность, диагностику потоков и времени. |
| `test_identity_and_many_passes` | Единичное ядро сохраняет матрицу после нескольких проходов при разных P. |
| `test_asymmetric_kernel_is_convolution` | Асимметричное ядро и два прохода совпадают с эталоном. |
| `test_subnormal_input_is_preserved` | Очень маленькие представимые double не отклоняются и не обнуляются. |
| `test_asymmetric_shift_has_known_answer` | Жёстко заданный ответ для ядра сдвига отдельно проверяет переворот ядра. |
| `test_kernel_larger_than_matrix` | Ядро больше матрицы и обработка краёв не дают неверных доступов. |
| `test_uneven_rows_and_fractional_values` | Дробные и отрицательные значения, неравные диапазоны и P больше числа строк совпадают с эталоном. |
| `test_sample` | Проверяет сохранённый пример и ожидаемый вывод. |
| `test_default_threads_and_help` | Проверяет лимит по умолчанию и справку. |
| `test_invalid_options` | Проверяет нулевые, отрицательные, дробные, переполненные и неизвестные параметры. |
| `test_invalid_data` | Проверяет неверные размеры, лишние/недостающие значения, NaN/Inf, ядро и K. |
| `test_computation_overflow` | Переполнение расчёта завершается ошибкой без вывода матрицы. |
| `test_output_failure` | Вывод в /dev/full приводит к обработанной ошибке записи. |
| `test_interactive_retry` | Через настоящий псевдотерминал проверяет повтор неверных строк и успешное завершение. |
| `test_thread_creation_and_join_failures` | Включает тестовые отказы pthread через переменные среды и проверяет завершение без результата и зависания. |
