# Лабораторная работа №3, вариант 13

Многопоточная обработка матрицы вещественных чисел на C с использованием POSIX threads.
Программа K раз применяет фильтр свёртки. Размеры и значения исходной матрицы,
размер и коэффициенты ядра, а также число проходов задаёт пользователь.

## Сборка и запуск

```sh
make
./convolution --threads 4
```

Параметр `--threads` задаёт максимальное число потоков, включая главный.
После запуска программа последовательно запрашивает входные данные.
